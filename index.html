Install NurLife on your home screen

First: the complete app package must be uploaded to an HTTPS website. Opening index.html from Downloads (a file:// address) cannot install a Progressive Web App.

Then on Android Chrome:
1. Open your HTTPS NurLife website.
2. Tap Chrome’s ⋮ menu.
3. Choose Install app or Add to Home screen.
4. Confirm the installation.

If the install button at the top becomes active, you can use that too. If Chrome does not offer installation, check that all package files were uploaded together and that the site opens with https://.
